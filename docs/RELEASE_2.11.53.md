# 吾爱云 Android 2.11.53

- 新增共用国外服务备用通道，覆盖提取码验证、首次导入、设备授权、订阅状态、订阅更新、心跳和流量上报。
- 保留国内直连优先；国内接口不可达时自动尝试国外备用，各品牌账户、设备和流量记录独立。
- 管理请求优先使用非 VPN 底层网络，减少全局模式下失效节点对订阅更新和账户检查的影响，无需临时切换代理模式。
- 流量补报保留未确认数据，后台最终确认后才完成；国内与备用路径重试不会重复累计用量。
- 订阅更新实时向原后台鉴权获取当前节点，失败保留原有效配置；一次性导入票据和设备/套餐限制保持。
- 保留打开软件首次刷新、每次启动刷新和手动更新，复用原应用签名与升级方式。

完全断网或主站及备用链路都不可达时无法获取新节点，已保存配置和未确认流量继续保留。正式打包完成后另行验证签名、分发和设备使用。
